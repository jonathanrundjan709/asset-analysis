# QA Checklist

Use this checklist before merging a Pull Request.

- [ ] Dashboard opens successfully in the Vercel Preview.
- [ ] Google Ads CSV upload works.
- [ ] Meta Ads CSV upload works.
- [ ] Asset summary renders correctly.
- [ ] Placement Analysis still works.
- [ ] Guardrail settings still work.
- [ ] Export CSV still works.
- [ ] No obvious layout issue on desktop.
- [ ] No console errors in browser devtools.
