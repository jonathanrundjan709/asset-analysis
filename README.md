# Google Ads Asset Dashboard

Static frontend dashboard for reviewing Google Ads app asset performance.

## Open in VS Code

Open this folder:

```bash
/Users/jonathanrundjan/Downloads/google-ads-dashboard
```

## Run locally

Because this is a static site, you can open `index.html` directly in a browser.

For a local server:

```bash
python3 -m http.server 4173
```

Then open:

```text
http://localhost:4173
```

## Deploy

```bash
npx vercel --prod --yes
```
